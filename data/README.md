\# Project Data



This directory contains datasets used for the AI-Based Resume Screening \& Job Matching System.



\## Structure



\- `raw/` - Original downloaded datasets

\- `processed/` - Cleaned and transformed datasets

\- `resumes/` - Resume-related data

\- `job\_descriptions/` - Job description data

\- `datasets/` - Final datasets prepared for model training and evaluation



\## Data Policy



Raw datasets should not be modified directly.



All preprocessing and transformations should produce files inside `processed/`.



Dataset sources and licenses will be documented before use.
