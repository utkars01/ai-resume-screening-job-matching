# Frontend – AI Resume Screening & Job Matching

This directory contains the React-based frontend for the AI Resume Screening & Job Matching application.

The interface provides recruiters with tools to manage applicants, upload resumes, review candidate profiles, create job postings, and view AI-powered candidate matching results.

## Technology Stack

- React
- Vite
- JavaScript
- CSS
- Vitest
- React Testing Library

## Prerequisites

- Node.js 22 LTS
- npm

## Installation

From the project root:

```powershell
cd frontend
npm ci
